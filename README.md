# gerarchia-tipografica-impaginazione

Riorganizza la gerarchia visiva di una pagina già scritta secondo il significato dei testi. Parte solo quando la chiami per nome.

Fa parte della [Prompt Library di CH Labs](https://www.cryptohelvetia.com/ch-labs/prompt-library), dove la pagina di riferimento è [Gerarchia tipografica impaginazione](https://www.cryptohelvetia.com/ch-labs/prompt-library/skills/gerarchia-tipografica-impaginazione). Il repo contiene una copia della skill, rigenerata a ogni aggiornamento della libreria.

## Installare

In Claude Code aggiungi una volta il marketplace e installa il plugin.

```
/plugin marketplace add MicheDada21/ch-labs-skills
/plugin install gerarchia-tipografica-impaginazione@ch-labs-skills
```

Da shell i comandi sono `claude plugin marketplace add MicheDada21/ch-labs-skills` e `claude plugin install gerarchia-tipografica-impaginazione@ch-labs-skills`. Nell'app desktop premi + accanto al campo del prompt, apri Plugins, aggiungi il marketplace `MicheDada21/ch-labs-skills` con Add marketplace e poi il plugin con Add plugin.

Con altri agenti copia la cartella `skills/gerarchia-tipografica-impaginazione` tra le skill dell'agente, per esempio in `~/.codex/skills/gerarchia-tipografica-impaginazione`.
